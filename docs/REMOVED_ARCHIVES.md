# Removed result archives — index

Every superseded result root that was deleted, and **why each was invalid**. The
reasons matter more than the file listings did: each one is a defect that a check
in the current pipeline now exists to prevent, so this file is the record of what
those checks are *for*. The file listings themselves were dropped — they
inventoried outputs of runs declared "not valid, not a specification, not a source
of numbers", and nothing reads them. The code states that produced them are in git
history.

**Live artifacts are `results/` (primary) and `results_verify/` (independent
reproduction at identical config). Nothing below is a source of numbers.**

---

## 2026-09-09 — `results_ARCHIVED_v1_invalid`

The first experimental programme, deleted after the restart.

* attack evaluation ran on 10–15 prompts;
* harmfulness and refusal were read at the **same** token position, rather than
  `t_inst` / `t_post-inst` respectively;
* `late_layer` (21) was earlier than `mid_layer` (23), so part of the
  cross-intervention matrix read *upstream* of its own intervention and produced
  exact `0.0` rows;
* `k_50` was undefined in every row;
* the RQ5 phase only ever ran under `FAST_DEV`.

## 2026-09-09 — `results_ARCHIVED_v2_pre_rebuild`

Produced before the PLAN/ENVIRONMENT/EXPERIMENTS rebuild, by code since corrected.

* `R_control` was fitted **role-pooled**, so it carried a role-composition
  component and was partly a role direction. Refusal rate varies strongly by role.
* layer selection used the **test** AUC in several places, so reported held-out
  numbers were partly selected on the evaluation split.
* the refusal-prefix list was hand-assembled rather than transcribed from Arditi
  et al., and matched over a 280-character window rather than their unbounded
  substring rule.
* the generation budget was fixed at 48 tokens rather than chosen by the
  pre-registered ladder rule.
* no per-model `run_manifest.json` — these outputs are not traceable to a commit.

## 2026-09-11 — slurm log layout

`slurm/1_run_phase/{out,err}` removed (93 + 93 files, 1.2 MB) along with
`tools/clean_slurm_logs.py`, which existed only to curate that flat directory by
mapping job ids to descriptions. Both obsolete: campaign jobs now log to
`slurm/logs/<RUN_TAG>/` (one directory per run, stamped with date and corpus size)
and ad-hoc submissions to `slurm/logs/adhoc/`, so "which job produced this" is
answered by the directory rather than a hand-maintained table.

Three logs are kept as primary evidence in `slurm/evidence/` — see its README.

## 2026-09-12 — `results_archive/` and `results_shakedown/` (152 MB)

Deleted once RQ1 settled on the six-model roster. Both had become **inert, not
merely old**, which is the bar for deleting evidence:

| removed | what it was | why it could not inform anything |
|---|---|---|
| `pre_5model_20260911/` | `results/` + `results_verify/` immediately before the six-model rerun — three Qwen models, MoE `causal` stage still running | Built on a **200/200 corpus** against the live **500/500**. `tools/diff_against_archive.py` refuses it by its own corpus-scale guard: every quantity would differ for that reason alone, so no DRIFT verdict carries information |
| `superseded_20260911_pre_scale/` | one generation older still, plus `results_probe/` and a pre-G3-fix shakedown | Same, and further from the live code |
| `results_shakedown/` | `FAST_DEV` smoke root on `qwen2.5-0.5b` | Regenerated by `blank_slate.sh` on every chain run; never a source of numbers |

**Two consumers depended on the archive; both were resolved before deletion, not
after:**

* `tests/test_verifier_teeth.py` took it as `TEETH_SOURCE`. Default repointed to
  `./results` and **re-verified: 9/9 mutations caught**. This is an improvement —
  the mutation suite now proves the verifier has teeth against the result set we
  actually report.
* `tools/diff_against_archive.py` defaulted to it and returned **exit 1** when the
  path was absent, which would have aborted `blank_slate_post.sh` mid-pass. A
  missing baseline is now a clean SKIP at exit 0, matching the corpus-scale skip
  beside it. The tool itself is kept: it takes any two roots as arguments and is
  immediately useful for comparing `results/` against `results_verify/`.

Also removed: generated figures under `results/figures/` (regenerable in seconds
from `results/` via `tools/make_figures.py`; which figures the paper actually needs
is deferred until RQ2–RQ4 are in) and `__pycache__` trees.
