# archive/ — superseded documents

Everything in this directory is from the project iteration that ended on 2026-09-15. It is
kept so that design caveats and environment facts can be cross-checked against what was
written before, and for no other purpose.

- Nothing here is a specification. New code is written against `plan.md`,
  `experiments.md` and `assumptions.md` in the repository root only.
- Nothing here is a result. Numbers in these files were produced by code that has since
  been withdrawn and are not evidence.
- Facts recorded here (templates, datasets, cluster behaviour) were re-entered in
  `assumptions.md` with status `unverified` and are re-checked there before use.

| File | Was |
|---|---|
| `PLAN.md` | the previous research plan (RQ1–RQ7, with the capitalised key system) |
| `EXPERIMENTS.md` | the previous experiment playbook, mixed with tentative results |
| `ENVIRONMENT.md` | the previous verified-facts file (source of the X and M entries in `assumptions.md`) |
| `README_old.md` | the previous repository landing page |
| `docs/` | RQ2/RQ3 pre-registrations, bug logs, RQ4 instrument decisions, RQ1 closure notes |
